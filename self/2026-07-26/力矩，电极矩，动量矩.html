力矩，电极矩，动量矩

  • SELF
  • 2026-07-26
  • 力矩，电极矩，动量矩

最准确的类比方式，是先把“矩”和“动量”分开：

  • 矩（moment）：某种空间分布对位置的加权积分；
  • 动量（momentum）：一个独立的动力学物理量，并不是“某阶矩”的同义词；
  • 角动量：动量分布关于位置的一阶叉乘矩；
  • 力矩/转矩：力分布关于位置的一阶叉乘矩；
  • 电偶极矩：电荷分布关于位置的一阶普通矩。

因此，最统一的比较应分为：

  1. 标量分布：质量、电荷、概率；
  2. 矢量分布：力、动量密度、电流；
  3. 相空间概率分布：可以统一表示平均动量、平均角动量、平均力矩等。

一、标量分布的各阶矩：质量—电荷—概率

设空间中的标量测度为 \(d\mu(\mathbf r)\)，定义 \(n\) 阶原点矩张量

\[ \boxed{ \mathbf M^{(n)} = \int \mathbf r^{\otimes n}\,d\mu(\mathbf r) } \]

其中

\[ \mathbf r^{\otimes n} = \underbrace{\mathbf r\otimes\cdots\otimes\mathbf r} _ {n\text{ 次}}. \]

三种最直接的对应是：

\[ d\mu= \begin{cases} dm=\rho_m\,dV,&\text{质量分布},\\ dq=\rho_q\,dV,&\text{电荷分布},\\ dP=f(\mathbf r)\,dV,&\text{概率分布}. \end{cases} \]

1. 各阶对应总表

阶数质量分布电荷分布概率分布主要含义
0阶\(\displaystyle M=\int dm\)\(\displaystyle Q=\int dq\)\(\displaystyle \int dP=1\)总量/归一化
1阶\(\displaystyle \mathbf D_m=\int\mathbf r\,dm=M\mathbf R_{\rm cm}\)\(\displaystyle \mathbf p=\int\mathbf r\,dq\)\(\displaystyle \boldsymbol\mu=E[\mathbf R]\)分布中心、偶极信息
2阶原始矩\(\displaystyle M_{ij}=\int r_ir_j\,dm\)\(\displaystyle C_{ij}=\int r_ir_j\,dq\)\(\displaystyle E[R_iR_j]\)尺度、方向性、各向异性
2阶中心矩质量协方差型张量中心化电荷二阶矩协方差矩阵 \(\Sigma_{ij}\)围绕中心的宽度和形状
2阶派生量转动惯量张量 \(I_{ij}\)电四极矩 \(Q_{ij}\)方差/协方差同一二阶矩的不同线性组合
3阶及以上质量多极矩电八极矩及更高电多极矩偏度、高阶联合矩更精细的不对称性和形状

2. 零阶量：总质量、总电荷、总概率

\[ \boxed{ M=\int\rho_m(\mathbf r)\,dV } \]

\[ \boxed{ Q=\int\rho_q(\mathbf r)\,dV } \]

\[ \boxed{ 1=\int f(\mathbf r)\,dV } \]

最直接的对应关系是：

\[ \boxed{ \text{总质量}\;\longleftrightarrow\; \text{总电荷}\;\longleftrightarrow\; \text{总概率} } \]

但是有一个重要区别：

  • 质量通常非负；
  • 概率必须非负且归一化为 \(1\)；
  • 电荷可正可负，总电荷甚至可以为零。

所以，概率分布在数学上更接近“归一化质量分布”，而不是一般电荷分布。

3. 一阶矩：质心、电偶极矩、期望位置

质量一阶矩

\[ \mathbf D_m=\int\mathbf r\,dm \]

质心为

\[ \boxed{ \mathbf R_{\rm cm} = \frac{1}{M}\int\mathbf r\,dm } \]

所以

\[ \boxed{ \mathbf D_m=M\mathbf R_{\rm cm} } \]

电荷一阶矩

\[ \boxed{ \mathbf p=\int\mathbf r\,dq } \]

这就是电偶极矩。

若总电荷 \(Q\neq0\)，可以形式上定义“电荷中心”

\[ \mathbf R_q=\frac{\mathbf p}{Q}. \]

但如果正负电荷同时存在，或者 \(Q=0\)，它不一定具有概率均值或质心那样的解释。

概率一阶矩

\[ \boxed{ \boldsymbol\mu=E[\mathbf R] =\int\mathbf r\,dP } \]

因此，最严格的数学对应是

\[ \boxed{ \frac{\mathbf D_m}{M} \longleftrightarrow \frac{\mathbf p}{Q} \longleftrightarrow E[\mathbf R] } \]

即

\[ \boxed{ \text{质心} \longleftrightarrow \text{电荷中心} \longleftrightarrow \text{概率均值} } \]

而未归一化的一阶矩对应为

\[ \boxed{ \mathbf D_m \longleftrightarrow \mathbf p \longleftrightarrow E[\mathbf R] } \]

其中概率的零阶量固定为 \(1\)，所以概率一阶矩本身就是均值。

二、二阶矩：转动惯量、电四极矩、协方差

这三个概念都来源于二阶张量

\[ \boxed{ M_{ij}^{(2)}=\int r_ir_j\,d\mu } \]

但它们对这个二阶矩进行了不同的组合。

1. 质量二阶矩与转动惯量

质量二阶原始矩：

\[ A_{ij}^{(m)} = \int r_ir_j\,dm. \]

转动惯量张量不是直接的 \(A_{ij}^{(m)}\)，而是

\[ \boxed{ I_{ij} = \int \left(r^2\delta_{ij}-r_ir_j\right)dm } \]

即

\[ \boxed{ \mathbf I = \operatorname{tr}(\mathbf A^{(m)})\mathbf 1 -\mathbf A^{(m)} } \]

绕单位轴 \(\mathbf n\) 的转动惯量为

\[ \boxed{ I_{\mathbf n} = \mathbf n^{\mathsf T}\mathbf I\mathbf n = \int \left[r^2-(\mathbf r\cdot\mathbf n)^2\right]dm } \]

它衡量的是质量到转轴的垂直距离平方的加权。

2. 电荷二阶矩与电四极矩

电荷二阶原始矩：

\[ C_{ij}^{(q)} = \int r_ir_j\,dq. \]

常见无迹电四极矩定义为

\[ \boxed{ Q_{ij}^{(e)} = \int \left(3r_ir_j-r^2\delta_{ij}\right)dq } \]

即

\[ \boxed{ \mathbf Q^{(e)} = 3\mathbf C^{(q)} -\operatorname{tr}(\mathbf C^{(q)})\mathbf 1 } \]

不同教材可能使用

\[ r_ir_j-\frac13r^2\delta_{ij} \]

作为定义，因此可能相差常数因子。

3. 概率二阶矩与协方差

概率二阶原始矩为

\[ \boxed{ E[\mathbf R\mathbf R^{\mathsf T}] } \]

协方差矩阵为

\[ \boxed{ \boldsymbol\Sigma = E\!\left[ (\mathbf R-\boldsymbol\mu) (\mathbf R-\boldsymbol\mu)^{\mathsf T} \right] } \]

满足

\[ \boxed{ \boldsymbol\Sigma = E[\mathbf R\mathbf R^{\mathsf T}] -\boldsymbol\mu\boldsymbol\mu^{\mathsf T} } \]

若把质量分布归一化为概率分布

\[ dP_m=\frac{dm}{M}, \]

则质量关于质心的协方差型张量为

\[ \boldsymbol\Sigma_m = \frac1M \int (\mathbf r-\mathbf R_{\rm cm}) (\mathbf r-\mathbf R_{\rm cm})^{\mathsf T}dm. \]

质心处的转动惯量张量满足

\[ \boxed{ \mathbf I_{\rm cm} = M\left[ \operatorname{tr}(\boldsymbol\Sigma_m)\mathbf 1 -\boldsymbol\Sigma_m \right] } \]

这给出了转动惯量和概率协方差之间的精确关系。

4. 二阶概念的最佳比较

基础二阶张量质量电荷概率
原始二阶矩\(\int r_ir_j\,dm\)\(\int r_ir_j\,dq\)\(E[R_iR_j]\)
中心二阶矩\(\int \Delta r_i\Delta r_j\,dm\)\(\int \Delta r_i\Delta r_j\,dq\)\(\operatorname{Cov}(R_i,R_j)\)
常用派生张量转动惯量张量电四极矩协方差矩阵
操作取“迹减原矩”取无迹对称部分中心化并归一化
物理/统计意义抗角加速度能力电荷分布各向异性及远场分布宽度、相关性、主轴

因此：

转动惯量、电四极矩和协方差不是完全相同的张量，但都由同一个二阶空间矩经过不同处理得到。

三、力矩与角动量：矢量分布的一阶叉乘矩

质量、电荷和概率通常是标量分布；力和动量密度则是矢量分布。

设一个矢量分布为 \(d\mathbf A(\mathbf r)\)，其零阶量为

\[ \mathbf A^{(0)}=\int d\mathbf A, \]

完整的一阶矩是二阶张量

\[ \boxed{ T_{ij} = \int r_i\,dA_j } \]

而叉乘矩是其反对称部分的矢量表示：

\[ \boxed{ \mathbf C = \int\mathbf r\times d\mathbf A } \]

或分量形式

\[ C_i=\epsilon_{ijk}T_{jk}. \]

1. 力分布：合力与力矩

对于力密度 \(\mathbf f(\mathbf r)\)：

零阶力矩量：合力

\[ \boxed{ \mathbf F = \int\mathbf f(\mathbf r)\,dV } \]

完整一阶力矩张量

\[ \boxed{ D_{ij}^{(F)} = \int r_if_j\,dV } \]

反对称部分：力矩/转矩

\[ \boxed{ \boldsymbol\tau = \int\mathbf r\times\mathbf f\,dV } \]

即

\[ \boxed{ \tau_i = \epsilon_{ijk}D_{jk}^{(F)} } \]

因此，通常所说的“力矩”只保留了完整一阶力矩张量的反对称部分；其对称部分也包含信息，在连续介质力学中可与力偶、应力偶极或 stresslet 等概念联系起来。

2. 动量分布：总动量与角动量

设动量密度为 \(\mathbf g(\mathbf r)\)。

零阶量：总线动量

\[ \boxed{ \mathbf P = \int\mathbf g(\mathbf r)\,dV } \]

完整一阶动量矩

\[ \boxed{ A_{ij}^{(P)} = \int r_ig_j\,dV } \]

反对称部分：角动量

\[ \boxed{ \mathbf L = \int\mathbf r\times\mathbf g\,dV } \]

所以最准确的关系是

\[ \boxed{ \text{总动量是动量密度的零阶空间矩} } \]

\[ \boxed{ \text{角动量是动量密度的一阶叉乘矩} } \]

而不是把“动量”和“一阶矩”直接等同。

3. 力与动量的动力学对应

牛顿第二定律给出

\[ \boxed{ \frac{d\mathbf P}{dt} = \mathbf F_{\rm ext} } \]

角动量定理给出

\[ \boxed{ \frac{d\mathbf L}{dt} = \boldsymbol\tau_{\rm ext} } \]

因此有非常直接的成对关系：

运动学/动力学量对应作用量
线动量 \(\mathbf P\)合力 \(\mathbf F=d\mathbf P/dt\)
角动量 \(\mathbf L\)力矩 \(\boldsymbol\tau=d\mathbf L/dt\)

从“阶数”看：

矢量分布零阶空间矩一阶叉乘矩
力分布合力 \(\mathbf F\)力矩 \(\boldsymbol\tau\)
动量分布总动量 \(\mathbf P\)角动量 \(\mathbf L\)
电流分布总电流密度积分 \(\int\mathbf J\,dV\)磁偶极矩 $ rJ,dV$

四、电学中与角动量最对应的是磁偶极矩

设电流密度为 \(\mathbf J(\mathbf r)\)。磁偶极矩定义为

\[ \boxed{ \boldsymbol\mu_{\rm mag} = \frac12 \int \mathbf r\times\mathbf J(\mathbf r)\,dV } \]

与角动量

\[ \boxed{ \mathbf L = \int \mathbf r\times\mathbf g(\mathbf r)\,dV } \]

形式高度相似：

\[ \boxed{ \text{动量密度 }\mathbf g \longleftrightarrow \text{电流密度 }\mathbf J } \]

\[ \boxed{ \text{角动量 }\mathbf L \longleftrightarrow \text{磁偶极矩 }\boldsymbol\mu_{\rm mag} } \]

这是比“角动量对应电偶极矩”更准确的类比。

1. 单粒子或同荷质比体系

对于电荷 \(q\)、质量 \(m\) 的粒子：

\[ \mathbf L=\mathbf r\times m\mathbf v, \]

电流产生的轨道磁矩为

\[ \boldsymbol\mu_{\rm orb} = \frac12\mathbf r\times q\mathbf v. \]

所以

\[ \boxed{ \boldsymbol\mu_{\rm orb} = \frac{q}{2m}\mathbf L } \]

若有多个具有相同荷质比 \(q/m\) 的粒子，也有

\[ \boxed{ \boldsymbol\mu_{\rm orb} = \frac{q}{2m}\mathbf L_{\rm orb} } \]

电子的 \(q=-e\)，因此电子轨道磁矩方向与轨道角动量相反：

\[ \boldsymbol\mu_{\rm orb} = -\frac{e}{2m_e}\mathbf L. \]

自旋磁矩还需引入 \(g\) 因子：

\[ \boxed{ \boldsymbol\mu_s = g\frac{q}{2m}\mathbf S } \]

2. 电偶极矩与磁偶极矩的区别

电学概念来源最对应的机械/统计概念
电偶极矩 \(\displaystyle \mathbf p=\int\mathbf r\,dq\)电荷的一阶普通矩质量一阶矩、概率均值
磁偶极矩 \(\displaystyle \boldsymbol\mu=\frac12\int\mathbf r\times\mathbf J\,dV\)电流的一阶叉乘矩角动量
电四极矩电荷二阶无迹矩质量四极矩、协方差的无迹部分
电偶极子受力矩 \(\boldsymbol\tau=\mathbf p\times\mathbf E\)外场对偶极子的作用磁矩在磁场中的转矩、机械取向力矩

五、电荷守恒将电偶极矩与电流联系起来

电荷连续性方程为

\[ \frac{\partial\rho_q}{\partial t} + \nabla\cdot\mathbf J =0. \]

电偶极矩

\[ \mathbf p=\int\mathbf r\rho_q\,dV. \]

对时间求导：

\[ \frac{d\mathbf p}{dt} = \int\mathbf r\frac{\partial\rho_q}{\partial t}\,dV. \]

利用连续性方程并假定边界通量消失，可得

\[ \boxed{ \frac{d\mathbf p}{dt} = \int\mathbf J\,dV } \]

因此：

  • 电荷分布的零阶矩是总电荷 \(Q\)；
  • 电荷分布的一阶矩是电偶极矩 \(\mathbf p\)；
  • 电流密度的体积分是电偶极矩的时间导数；
  • 电流分布的一阶叉乘矩是磁偶极矩。

对应关系可以写成：

\[ Q \quad\longrightarrow\quad \mathbf p \quad\longrightarrow\quad \dot{\mathbf p}=\int\mathbf J\,dV, \]

而

\[ \mathbf J \quad\xrightarrow{\text{一阶叉乘矩}}\quad \boldsymbol\mu_{\rm mag}. \]

六、概率论中如何对应动量、角动量和力矩

单纯的位置概率分布 \(f(\mathbf r)\) 只能定义位置的各阶矩，不能单独定义动量或角动量。要对应这些动力学量，需要使用相空间概率分布

\[ f(\mathbf r,\mathbf p,t). \]

归一化条件为

\[ \int f(\mathbf r,\mathbf p,t)\,d^3r\,d^3p=1. \]

1. 相空间中的各类期望

平均位置

\[ \boxed{ E[\mathbf R] = \int\mathbf r f(\mathbf r,\mathbf p)\,d^3r\,d^3p } \]

平均动量

\[ \boxed{ E[\mathbf P] = \int\mathbf p f(\mathbf r,\mathbf p)\,d^3r\,d^3p } \]

平均角动量

\[ \boxed{ E[\mathbf L] = E[\mathbf R\times\mathbf P] } \]

即

\[ \boxed{ E[\mathbf L] = \int (\mathbf r\times\mathbf p) f(\mathbf r,\mathbf p)\,d^3r\,d^3p } \]

平均力矩

\[ \boxed{ E[\boldsymbol\tau] = E[\mathbf R\times\mathbf F] } \]

即

\[ \boxed{ E[\boldsymbol\tau] = \int [\mathbf r\times\mathbf F(\mathbf r,\mathbf p)] f(\mathbf r,\mathbf p)\,d^3r\,d^3p } \]

在适当条件下，

\[ \boxed{ \frac{d}{dt}E[\mathbf P] = E[\mathbf F] } \]

\[ \boxed{ \frac{d}{dt}E[\mathbf L] = E[\boldsymbol\tau] } \]

2. 概率论中的最佳对应

物理量概率论表达
质心\(E[\mathbf R]\)
平均速度\(E[\mathbf V]\)
平均动量\(E[\mathbf P]\)
平均角动量\(E[\mathbf R\times\mathbf P]\)
平均力\(E[\mathbf F]\)
平均力矩\(E[\mathbf R\times\mathbf F]\)
转动惯量\(M E[r^2\mathbf1-\mathbf R\mathbf R^{\mathsf T}]\)
动量涨落\(\operatorname{Cov}(\mathbf P)\)
位置涨落\(\operatorname{Cov}(\mathbf R)\)
位置—动量关联\(\operatorname{Cov}(\mathbf R,\mathbf P)\)

需要强调：

\[ \boxed{ E[\mathbf R\times\mathbf P] \neq E[\mathbf R]\times E[\mathbf P] } \]

一般有

\[ E[\mathbf R\times\mathbf P] = E[\mathbf R]\times E[\mathbf P] + E[(\mathbf R-E\mathbf R)\times(\mathbf P-E\mathbf P)]. \]

第二项代表位置与动量涨落之间的关联，也就是相对于概率中心的“内禀”平均角动量。

七、原点平移性质的统一比较

设新原点相对旧原点移动 \(\mathbf a\)：

\[ \mathbf r'=\mathbf r-\mathbf a. \]

1. 标量分布的一阶矩

若总标量为

\[ S=\int d\mu, \]

一阶矩为

\[ \mathbf D=\int\mathbf r\,d\mu, \]

则

\[ \boxed{ \mathbf D'=\mathbf D-\mathbf aS } \]

具体为：

量平移公式
质量一阶矩\(\mathbf D_m'=\mathbf D_m-M\mathbf a\)
电偶极矩\(\mathbf p'=\mathbf p-Q\mathbf a\)
概率均值\(E[\mathbf R']=E[\mathbf R]-\mathbf a\)

所以：

  • 中性体系 \(Q=0\) 的电偶极矩与原点无关；
  • 质量一阶矩依赖原点，但质心随坐标一起平移；
  • 概率中心矩不随整体平移改变。

2. 矢量分布的叉乘矩

若

\[ \mathbf A=\int d\mathbf A, \qquad \mathbf C=\int\mathbf r\times d\mathbf A, \]

则

\[ \boxed{ \mathbf C' = \mathbf C-\mathbf a\times\mathbf A } \]

对应为：

量平移公式与原点无关的条件
力矩\(\boldsymbol\tau'=\boldsymbol\tau-\mathbf a\times\mathbf F\)合力 \(\mathbf F=0\)
角动量\(\mathbf L'=\mathbf L-\mathbf a\times\mathbf P\)总动量 \(\mathbf P=0\)
磁偶极矩\(\boldsymbol\mu'=\boldsymbol\mu-\frac12\mathbf a\times\int\mathbf J\,dV\)稳恒局域电流通常 \(\int\mathbf J\,dV=0\)

这揭示了一个非常强的统一结构：

\[ \boxed{ \begin{aligned} \mathbf p'&=\mathbf p-\mathbf aQ,\\ \boldsymbol\tau'&=\boldsymbol\tau-\mathbf a\times\mathbf F,\\ \mathbf L'&=\mathbf L-\mathbf a\times\mathbf P. \end{aligned} } \]

高阶矩对原点的依赖总是由更低阶矩控制。

九、最简洁的对应结论

最“对应”的比较可以归纳为四组：

1. 标量分布的普通矩

\[ \boxed{ \text{质量矩} \longleftrightarrow \text{电荷多极矩} \longleftrightarrow \text{概率矩} } \]

其中

\[ \boxed{ \text{质量一阶矩} \longleftrightarrow \text{电偶极矩} \longleftrightarrow \text{均值} } \]

\[ \boxed{ \text{质量二阶矩/转动惯量} \longleftrightarrow \text{电四极矩} \longleftrightarrow \text{协方差} } \]

但后三者只是共享二阶基础张量，并非完全相同的张量组合。

2. 矢量分布的零阶矩

\[ \boxed{ \text{总动量} \longleftrightarrow \text{合力} \longleftrightarrow \int\mathbf J\,dV } \]

它们分别是动量密度、力密度、电流密度的空间积分。

3. 矢量分布的一阶叉乘矩

\[ \boxed{ \text{角动量} \longleftrightarrow \text{力矩} \longleftrightarrow \text{磁偶极矩} } \]

其共同结构分别为

\[ \boxed{ \mathbf L=\int\mathbf r\times d\mathbf P } \]

\[ \boxed{ \boldsymbol\tau=\int\mathbf r\times d\mathbf F } \]

\[ \boxed{ \boldsymbol\mu_{\rm mag} = \frac12\int\mathbf r\times d\mathbf I = \frac12\int\mathbf r\times\mathbf J\,dV } \]

4. 概率论中的统一形式

若使用相空间随机变量 \((\mathbf R,\mathbf P)\)，则

\[ \boxed{ \begin{aligned} \text{平均位置}&=E[\mathbf R],\\ \text{平均动量}&=E[\mathbf P],\\ \text{平均角动量}&=E[\mathbf R\times\mathbf P],\\ \text{平均力矩}&=E[\mathbf R\times\mathbf F]. \end{aligned} } \]

所以概率论不是给每个物理量提供一个不同的“概率版本”，而是提供统一操作：

\[ \boxed{ \text{把对应物理函数取期望} } \]

其中最重要的概念区分是：

\[ \boxed{ \text{电偶极矩对应质量一阶矩；磁偶极矩对应角动量。} } \]
